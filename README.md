# HRITANI Site Setup — بلوجن التثبيت الكامل

> **فكرتك** — بدل نقل ملفات يدوياً: **بلوجن واحد يُثبّت الموقع كاملاً بنقرة واحدة**.
> عند تفعيله على أي WordPress نظيف، يبني الموقع تلقائياً.

---

## 📦 ماذا يفعل البلوجن عند التفعيل؟

| # | المهمة | الطريقة |
|:--|:--|:--|
| 1 | **الإعدادات الأساسية** | `update_option()` — اسم الموقع، الوصف، المنطقة الزمنية، بداية الأسبوع |
| 2 | **تثبيت الثيم hritani** | من ZIP مضمّن داخل البلوجن (`themes/hritani.zip`) — إن لم يكن موجوداً |
| 3 | **تفعيل الثيم** | `switch_theme('hritani')` |
| 4 | **إنشاء 4 صفحات** | `wp_insert_post()` — الرئيسية، منتجاتنا، من نحن، تواصل معنا |
| 5 | **الصفحة الرئيسية = الواجهة** | `show_on_front=page` + `page_on_front` |
| 6 | **إنشاء القائمة** | صفحة لكل عنصر + ربطها في موقع `primary` |
| 7 | **رسالة نجاح** | `admin_notices` — للمستخدم |

---

## 🧰 الاستخدام على سيرفر جديد

```
1. انسخ مجلد البلوجن:
   wp-content/plugins/hritani-site-setup/

2. من لوحة التحكم:
   الإضافات → أضف جديداً → رفع إضافة → hritani-site-setup.zip
   أو من FTP مباشرة إلى wp-content/plugins/

3. فعّل البلوجن → كل شيء يُبنى تلقائياً
```

## ⚙️ ما يجب تعديله في الإعدادات (Settings) — حسب البنية

### 1. قاعدة البيانات:
| البنية | الإجراء |
|:--|:--|
| **MySQL (استضافة عادية)** | لا شيء — WP الافتراضي يستخدم MySQL تلقائياً |
| **SQLite (مثل سيرفرنا)** | ثبّت بلوجن `sqlite-database-integration` + انسخ `wp-content/database/` |

### 2. عناوين الموقع (إعدادات → عام):
```
عنوان WordPress (URL):   https://<نطاقك>
عنوان الموقع (URL):      https://<نطاقك>
```
> ⚠️ **مهم جداً:** إذا كان العنوان القديم مختلفاً، غيّره هنا **قبل** أي شيء.
> وإلا ستبقى الروابط القديمة (mixed content). استخدم `Better Search Replace` لاحقاً إن لزم.

### 3. الثيم:
- بعد التفعيل ✅ الموقع يستخدم `hritani` تلقائياً
- للتخصيص: عدّل ملفات `wp-content/themes/hritani/` مباشرة (التصميم هناك 100%)

### 4. القائمة (المظهر → القوائم):
- "القائمة الرئيسية" أُنشئت + رُبطت في موقع `primary`
- لتعديل عناصرها: المظهر → القوائم → اسحب/أفلت أو أضف

### 5. الإضافات المطلوبة:
| الإضافة | ضرورية؟ | السبب |
|:--|:--:|:--|
| `sqlite-database-integration` | للـ SQLite فقط | إذا كانت قاعدة البيانات SQLite |
| `akismet` | لا | مضمنة افتراضياً |

## 🔄 إعادة التشغيل النظيفة (استخدمتها للاختبار)

```bash
# على أي WP نظيف:
wp plugin activate hritani-site-setup
# → يبني: صفحات + قائمة + إعدادات + ثيم
```

**الاختبارات التي مرّ بها البلوجن:**
- ✅ PHP syntax سليم
- ✅ تفعيل نظيف يبني 4 صفحات
- ✅ حذف الصفحات ثم إعادة التفعيل → يعيد بناءها
- ✅ بدون أي تحذيرات deprecated
- ✅ الصفحة الرئيسية = الواجهة
- ✅ قائمة primary (4 عناصر)
- ✅ موقع حي 200 + بطاقات 8 + قائمة 4 روابط
